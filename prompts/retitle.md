## 情况
前序步骤已经选出了值得发布的片段（时间范围已确定），但在为它们起标题时出现了问题：
{{ISSUE}}

## 你的任务
**只重新生成标题与简介**，不要改动时间范围，不要增删片段。

## 你会收到
每个片段的：序号、时间范围、该时间段内的转写文本摘录与弹幕信号、之前的标题（可能不合规）。

## 输出要求
只输出一个 JSON 对象，不要解释文字，不要 Markdown 代码围栏：

{
  "titles": [
    { "index": 片段序号（数字）, "title": "新标题", "desc": "新简介", "tags": ["标签"] }
  ]
}

## 硬性约束（这是本次重试要解决的问题）
- `title` **不超过 80 个字符**。请直接用 `String.length` 的口径估算：中文字、英文字母、数字、标点、空格都算 1 个字符。
- `desc` **不超过 250 个字符**。
- `tags` **1 到 10 个**，去重，每个 ≤ 12 字。
- 标题要具体、有钩子，不要"精彩片段""高能时刻"这类无信息量的写法。
- 不要编造输入里没有的内容。
- 不要写入任何技术标记、哈希、编号。
